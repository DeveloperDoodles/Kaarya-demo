# Kaarya — live demo

**Try it:** https://developerdoodles.github.io/Kaarya-demo/

Kaarya is an office task app: administrators assign work in a person's feed, and Kaarya tracks it with
deadlines, priorities, live status, reminders, repeating tasks, reports and a Recurring Tasks register. The office's own
purchase and sales registers are shown greyed out: they aren't part of the demo.
It runs entirely on one PC on the office network, with no cloud and no internet needed.

This demo is the real app's interface running on made-up data inside your browser. Nothing is sent
anywhere, and the data resets when you close the tab. Sign in with one click as an administrator or
an employee.
